# Aplicativo de Controle de Refeições

## 📌 Sobre o App
Este aplicativo tem como objetivo auxiliar no **controle de refeições** de uma pessoa, permitindo a realização de um CRUD (*Create, Read, Update, Delete*) das refeições cadastradas.  

Os campos disponíveis para cadastro são:
- **Nome da refeição**
- **Descrição da refeição**
- **Data da realização da refeição**
- **Horário da realização da refeição**

## 🔄 Fluxo de Navegação
O processo de uso do aplicativo segue o seguinte fluxo:

  - Exibir porcentagem de refeições (ao clicar, mostra informações gerais sobre a dieta)
  - Criar nova refeição (permite cadastro)
  - Selecionar refeição cadastrada → **Editar refeição**
  - Selecionar refeição cadastrada → **Excluir refeição**

Esse é o fluxo geral de utilização do aplicativo.
